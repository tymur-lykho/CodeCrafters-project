# CodeCrafters Project – Портфоліо Frontend-розробника

[Відкрити сайт](https://tymur-lykho.github.io/CodeCrafters-project/)

**CodeCrafters** — це сучасне односторінкове портфоліо, створене для
демонстрації навичок та досвіду фронтенд-розробника.  
Проєкт реалізовано з використанням HTML, CSS, JavaScript.  
Сайт включає адаптивний дизайн, анімації, модальні вікна, інтерактивні елементи
та інтуїтивну навігацію.

---

## 🔍 Структура сторінки

- **Hero Section** — вступна частина з ім’ям, роллю та соцмережами.
- **About Me** — детальний опис досвіду, навичок та стеку технологій.
- **Benefits** — переваги роботи з розробником.
- **Projects** — приклади реалізованих проєктів із тегами технологій.
- **FAQ** — відповіді на поширені запитання.
- **Covers** — галерея замовлень (креативних робіт).
- **Reviews** — відгуки клієнтів.
- **Work Together** — форма для контакту з можливістю надіслати повідомлення
  (модальне вікно).
